What I Built

เป็นหน้าเว็บไซต์portfolioใบแรกของฉัน สร้างด้วย HTML และCSS ซึ่งแบ่งออกเป็น4ส่วน คือ แนะนำตัวเอง,อธิบายเกี่ยวกับงาน,ขั้นตอนการทำงาน และการสะท้อนความคิด

วิเคราะห์ Client/Server: ขณะเปิดดูเว็บจากเครื่องตัวเอง จะเกิดเฉพาะด้าน Client เท่านั้น ไม่มีการใช้งาน Server

How I Built It

เริ่มจากวางโครงสร้างโฟลเดอร์และไฟล์ จากนั้นเขียนโครงสร้างHTMLเขียนเนื้อหาที่ต้องการลงไป จากนั้นตกแต่งด้วยCSSเพื่อให้สวยงามและน่าสนใจมากขึ้น โดยใช้เครื่องมือ VS Code ในการเขียนโค้ด และใช้แหล่งข้อมูลออนไลน์เช่น W3Schools เพื่อศึกษาเพิ่มเติมเกี่ยวกับ HTML และ CSS
